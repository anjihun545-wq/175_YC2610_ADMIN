# v1.4 검증 보고서

## 현재 자동화 확인

- JavaScript `node --check`: 웹 클라이언트 파일 모두 통과
- 기존 번호 고정 계측 테스트: 개인전 200명, 단체전 50팀 총 250회 연속 시작/종료, 번호 자동 이동, 완료 번호 재시작 차단
- 모의 서버 연동: 저장 대기열, 오프라인 상태에서 종료 기록 보관, 복구 후 재전송
- 모의 Apps Script 서버: 개인전 200 + 단체전 50 = 500회 기록 변경, 중복 요청 ID 차단, 다른 기기의 잠금 획득 차단, 개인/전체 초기화, 이전 초기화 버전 기록 거부, JSONP 응답
- PC(1400px) / 모바일(390px) Chromium 조작 시험: 시작·종료·번호 자동 이동, JSON 백업, 개인전만 초기화, 레이아웃 가로 넘침 없음 — 통과 (Apps Script 미연결 상태)
- 읽기 쉬운 Google Sheets `YC_RESULTS` 250개 기록 행 생성·갱신 — 가상 스프레드시트 시험 통과
- 전체 설정값 교체: Firebase SDK를 불러오지 않는 구성

## 아직 실제 현장 검증이 필요한 항목

- Google Apps Script의 `/exec` 실제 웹 앱 배포 및 `GET` JSONP / `POST` HTML 폼 동작
- Google 계정/브라우저/기기에서 리디렉션 및 보안 정책 영향
- 운영 노트북과 MC 휴대전화의 실제 지연 시간
- 초당 요청·Google Apps Script 서비스 할당량 도달 여부
- 앱 강제 종료·로컬 저장 실패·Google Sheets 일시 장애·복구 시나리오
- 경기 중 기기 교체, 중복 계측 경쟁, 종료 기록 이중 확인
- 현장 보조 스톱워치/결승선 영상과의 시간 오차 대조

결론: **GitHub 업로드 + Google Sheets Apps Script 배포용 개발 파일 완성. 실제 서버 연동/실전 검증 미완료.**
