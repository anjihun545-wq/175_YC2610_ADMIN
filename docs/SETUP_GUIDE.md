# v1.5 초보자 배포 안내

## 먼저 백업하기

1. 현재 GitHub 프로그램(v1.4)에서 **운영·백업** → 전체 CSV 및 JSON 백업 다운로드.
2. 경기 진행 중이라면 v1.4 화면에서 경기 종료 처리. v1.5로 교체 후에는 v1.4의 오래된 진행 기록을 직접 종료할 수 없습니다.
3. 지금까지 입력한 기록은 서버에 남습니다. 현장 리허설을 새로 시작하려면 **백업을 확인하고** 개인전 또는 전체 초기화를 시행하세요.

## 1. GitHub 파일 업로드

1. ZIP을 압축 풉니다.
2. GitHub 저장소 https://github.com/anjihun545-wq/175_YC2610_ADMIN 에 접속합니다.
3. 압축 푼 폴더 **안의 모든 내용**을 저장소 맨 위(루트)에 업로드하고 기존 파일을 교체합니다.
4. 꼭 `index.html`, `style.css`, `js/app.js`, `js/core.js`, `js/heat.js`, `js/cloud.js`, `js/storage.js`, `js/apps-script-config.js`가 저장소에 있는지 확인합니다.
5. Settings → Pages에 main / root가 설정되어 있는지 확인합니다.

> 참고: GitHub Pages URL은 보통 https://anjihun545-wq.github.io/175_YC2610_ADMIN/ 입니다.

## 2. Apps Script 웹 앱 기존 배포 갱신 (필수)

1. 경기 기록이 저장되는 **기존 Google Sheets**를 엽니다.
2. **확장 프로그램 → Apps Script**로 들어갑니다.
3. `Code.gs` 내용을 모두 지우고 이번 ZIP의 `apps-script/Code.gs` 전체를 붙여넣은 후 저장합니다.
4. 함수 선택 드롭다운에서 `setup` → 실행. 기존 기록을 삭제하지 않고 `YC_RESULTS` 시트에 **부문** 열을 포함한 8개 열의 결과표를 다시 만듭니다.
5. 우상단 **배포 → 배포 관리**에서 **기존 웹 앱 배포**의 편집 연필을 누릅니다.
6. 버전을 **새 버전(New version)** 으로 선택한 뒤 **배포**합니다. 새로운 배포를 만들지 않아야 기존 `/exec` URL이 유지됩니다.
7. 기존 주소 끝에 `?action=ping` 을 추가해 페이지를 열고 `"ok":true`와 `"YC2026 Apps Script v1.5"`가 나오는지 확인합니다.

> 이번 ZIP의 `js/apps-script-config.js`는 이전 대화에서 제공한 기존 `/exec` URL을 유지하고 있습니다. 배포를 새 URL로 만들었다면 이 파일도 바꿔야 합니다.

## 3. 계측 테스트

1. PC에서 홈페이지를 열고 `서버 저장 확인 정상`을 기다린 다음 **계측 제어권 획득**을 클릭합니다.
2. **남자 개인전 M001조**(001 / 002) 확인 → **두 선수 동시 시작**.
3. **B 종료**(002번)를 먼저 누르고 A 타이머가 계속 작동하는지 확인합니다.
4. **A 종료**(001번)를 누릅니다. 잠정 기록이 두 개 남고 **M002조**로 이동해야 합니다.
5. 다른 모바일 기기에서 `?view=mc`를 열어 남자부 001 / 002 기록이 표시되는지 확인합니다.
6. 시트의 `YC_RESULTS`에서 001·002 두 줄 모두 기록되는지 확인합니다.
7. **여자 개인전 F001조**(151 / 152)도 시험하고 남녀 순위가 분리되는지 확인합니다.
8. **계주 스톱워치**에서 시작 → 정지 → 초기화를 누릅니다. 계주 결과는 서버로 저장되지 않습니다.
9. 인터넷을 일시 차단하여 **진행 중 개인전 기록을 각각 종료할 수 있는지**, 연결 복구 후 미전송이 0건이 되는지 확인합니다. 공식 실전 전에 반드시 현장 기기로 시험하세요.
10. 테스트 기록을 CSV/JSON으로 백업하고, 기록 초기화 여부를 판단한 뒤 실제 경기를 시작하세요.

## 운영 시 주의

- 기록 저장/확정 전에 브라우저를 닫지 마세요. 출발/도착 담당자는 한 기기에 모여 조작하는 편이 안전합니다.
- 두 명이 동시에 결승선에 들어오면 버튼 입력 오차가 발생할 수 있으므로 보조 영상이 필요합니다.
- `Space` 공동출발 / 숫자 `1` A종료 / 숫자 `2` B종료.
- Apps Script 조회는 약 5초마다 이뤄집니다. Firebase 같은 실시간 푸시 기능이 아닙니다.
- 로그인 없는 웹 앱은 **누구나 데이터 변경 요청을 할 수 있는 보안 위험**이 있습니다.
