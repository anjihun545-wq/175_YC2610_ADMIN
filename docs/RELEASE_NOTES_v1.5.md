# v1.5 새 기능
- 남자 개인전 001~150번, 여자 개인전 151~200번 각각 2인 동시 출발.
- 공통 시작 버튼 1개, 개별 종료 A/B 2개; 개별 타이머 독립 종료.
- 남자 75개 조 + 여자 25개 조, 총 100개 조 자동 구성.
- 남/여 순위 및 CSV 분리.
- 계주는 저장 기능 없는 독립 스톱워치 시작/정지/초기화만 제공.
- Apps Script 결과표에 성별 열 추가, 동시 출발 2명 상태 모두 업데이트.
- Apps Script 설정 URL 그대로 유지. 기존 Apps Script 배포의 **새 버전 배포** 필요.
