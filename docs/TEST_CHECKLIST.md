- [ ] 실격·미완주 처리 뒤 다음 번호 진행
- [ ] 잠정 기록 수정·취소·재경기, 이력 저장
- [ ] 전체 CSV 250개 번호/팀 행과 기록 검증
- [ ] Firebase 실제 접속 후 계측 기기→MC 다른 기기 반영
- [ ] 인터넷 차단 후 미전송 및 복구 재전송/중복 방지
- [ ] 계측 기기 강제 종료/브라우저 재개, 보조 기록과 비교
- [ ] 관리자/조회자 계정 권한 보안 테스트

# 운영 전 테스트 및 확인서

## 제작 단계에서 확인한 것

- JavaScript 구문 검사: `js/app.js`, `js/core.js`, `js/cloud.js`, `js/storage.js`
- 브라우저 모의환경(서버·저장 인터페이스 대체)에서 개인 참가자 등록, 개인전 시작/종료, 개인전 순위, 4인 계주팀 등록, 계주 시작/종료, MC 화면 표시, CSV 다운로드 동작 확인
- 모의 테스트 중 등록 폼 ID 충돌 버그를 발견하여 수정한 뒤 재시험

## 아직 검증하지 못한 것 (Firebase 프로젝트 연결 필요)

- [ ] 실제 이메일/비밀번호 운영자 로그인 및 MC(viewer) 권한 분리
- [ ] 실제 Firebase Rules 배포 후 관리자 쓰기 성공 / 조회자 쓰기 거부
- [ ] 여러 기기 간 기록 반영 시간 측정 (목표: 정상망에서 1초 내, **보장 아님**)
- [ ] 실제 IndexedDB에 200명 이상 등록 후 새로고침 유지
- [ ] 네트워크 30초~5분 차단 후 정상 재전송과 중복 방지
- [ ] 200명 개인 경기 연속 시작/종료 및 CSV 대조
- [ ] 4인 계주 여러 팀 순차 계측 / 빠른 연속 클릭 방지
- [ ] 동시에 두 운영자가 제어권 획득할 때 충돌 방지
- [ ] 브라우저 종료·재시작 시 중단 경기 추정치 경고와 복구
- [ ] Firebase 사용량, 비용 한도, 장시간 행사 중 접속 안정성 확인
- [ ] 실제 행사장 네트워크 및 보조 스톱워치/결승 영상 확인

## 행사 운영 체크

- [ ] 참가자 명단 200명 또는 실제 최종 명단 반영
- [ ] 계주팀별 선수 4명 구성 확인
- [ ] 경기 시작 전 20회 이상 타이머 조작 연습
- [ ] 계측 노트북 절전/자동 업데이트/알림 방지 설정
- [ ] MC 화면이 참가자 개인정보를 외부에 노출하지 않도록 현장 위치 관리
- [ ] 공식 결과 확정 담당자 지정
- [ ] 경기 중 매 조별 보조 기록 확보
- [ ] 종료 직후 CSV 전체 기록 및 계측 이력 백업

## 정확도와 결과 판정

시간은 0.01초까지 표시하지만 버튼을 누르는 사람의 반응속도와 브라우저 실행 지연 때문에 실제 계측 정확도는 이 단위만큼 보장되지 않습니다. 접전 시 영상과 심판의 보조기록을 우선 확인한 후 공식 기록을 확정하세요.
