# 2026 연천피지컬 서바이벌 · 경기 계측 v1.5

**개인전: 두 명이 하나의 출발 버튼으로 동시에 시작, 결승선 종료 버튼은 A/B 각각 따로.**
**계주: 팀번호 및 서버 기록을 사용하지 않는 단순 스톱워치(시작/정지/초기화).**

## 운영 규칙

- 전체 200명 고정번호 중 **남자 001~150**, **여자 151~200**으로 기본 편성합니다. (별도 이름 등록 없음)
- **남자부 75개 조**, **여자부 25개 조**, 총 **100개 조**. 각 조 2명입니다.
- 1조 A=001, B=002 / 2조 A=003, B=004 / 여자 1조 A=151, B=152 등.
- 두 주자 **동일한 출발 시각**, 이후 A 종료/B 종료 각각 독립 처리. A가 종료되어도 B 타이머는 계속 움직입니다.
- 종료된 선수는 잠정 순위에 즉시 반영됩니다. 남녀 순위 구분 및 수정/확정 지원.
- 단축키 **Space** 공통 시작 / **1** A 종료 / **2** B 종료. 결승선 담당자에게 적절한 입력 장치를 배치하세요.
- 계주 화면은 **기기 전용 스톱워치**입니다. 계주 결과를 Google Sheets에 저장하거나 순위를 매기지 않습니다.
- 2인 개인전 중 미완주 또는 실격 처리는 각각 별도 버튼으로 처리합니다.
- 1개 조 두 명이 모두 완료되어야 자동으로 다음 조가 선택됩니다.

> ⚠ **남자 001~150 / 여자 151~200 번호 구분은 기본 설계 가정입니다.** 현장 참가번호 부여 방식이 다르면 배포 *전에* `js/heat.js`와 `js/core.js`를 함께 변경해야 합니다. 남녀를 섞은 2인 1조는 지원하지 않습니다.

## 저장 / 서버

- `js/apps-script-config.js`에 이미 제공받은 Apps Script `/exec` 주소가 들어 있습니다. GitHub Pages 정적 업로드는 별도 설치 과정이 필요 없습니다.
- 시작 및 개별 종료 기록은 IndexedDB에 먼저 저장한 뒤 Google Apps Script로 전송합니다.
- Apps Script가 저장 요청 ID를 ACK하면 `미전송` 목록에서 제거합니다.
- MC 화면 `?view=mc`는 약 **5초 간격**으로 Google Apps Script의 기록을 조회합니다(즉시 반영을 보장하지 않음).
- 서버 1번의 시작과 2번의 종료가 별도 작업으로 이뤄지므로 이전 v1.4보다 앱스크립트 통신 빈도가 늘어납니다.
- **Apps Script 배포를 새 버전으로 갱신해야 Google Sheets의 두 선수 진행 상태가 모두 정확하게 반영됩니다.** 이전 v1.4 Code.gs를 유지하면 웹앱의 기록 저장은 가능할 수 있으나 `YC_RESULTS` 시트의 진행 중 두 행이 모두 반영되지 않습니다.

## 설치 / 업데이트

반드시 `docs/SETUP_GUIDE.md` 문서를 따라 주세요.

1. **기존 v1.4 기록을 CSV + JSON으로 백업**하세요.
2. v1.4에서 진행 중인 경기를 종료하고, 필요하면 이전 테스트 기록을 백업 후 초기화합니다.
3. GitHub 저장소 루트에 ZIP 내부 파일들을 덮어씁니다 (`index.html`, `js/` 등).
4. Google Sheets > **확장 프로그램 > Apps Script**에서 `apps-script/Code.gs` 전체를 교체합니다.
5. `setup()`을 다시 실행하여 `YC_RESULTS`의 **부문 열**을 생성합니다.
6. Apps Script **배포 > 배포 관리 > 기존 배포 수정 > 버전: 새 버전 > 배포**. 기존 `/exec` URL을 유지하세요.
7. 프로그램과 MC URL에서 2인 동시 출발·각 종료·남녀 순위·계주 스톱워치를 검증합니다.

## 배포 전 검증

- `npm test` 통과: 200명 100조 순차 계측, A/B 개별 종료 순서, 중복 방지, 모의 Apps Script 300건 기록 및 Google Sheet 결과표.
- Chromium 실제 페이지/터치 시험은 실행 환경 보안 제한으로 **완료하지 못했습니다**.
- 실제 Apps Script 구글 서버 / 행사장 네트워크 연결 시험도 **미완료**입니다.

## 보안 / 장애

- 기존과 마찬가지로 로그인 없는 공개 Apps Script이며 **URL을 아는 사람은 기록 조회·수정·초기화를 요청할 수 있습니다.** 행사 공식 운영에는 별도 쓰기 접근 보호를 권장합니다.
- 한 대에서만 출발/종료, 다른 장비는 `?view=mc` 조회에 사용하세요.
- 0.01초 표시 가능 ≠ 수동 버튼의 계측 정확도 보장. 접전 판정용 영상·보조 스톱워치를 병행하세요.
- 인터넷 연결이 끊긴 상태에서 새 조 출발은 차단하고, **진행 중 두 선수의 종료는 각각 기기 저장**하도록 설계했습니다. 단, 기기 데이터 삭제나 고장은 방어할 수 없습니다.
- 예전 v1.4 단체전 50팀의 서버 기록은 새 화면에서 숨기지만 삭제하지 않습니다. 초기화 메뉴의 **전체 기록**을 선택한 경우에만 지워집니다.
