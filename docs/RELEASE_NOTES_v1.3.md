# v1.3 변경 내역

- 운영자/MC 이메일 로그인, 비밀번호 입력 화면 제거
- 자동 Firebase 익명 인증 도입 (콘솔에서 Anonymous 활성화 필요)
- `?view=mc`를 조회 위주 UI로 유지. **서버 수준 편집 권한 분리는 제공하지 않음**
- `database.rules.json`을 익명 인증 이벤트 경로로 변경
- 개인전만 / 단체전만 / 전체 기록 초기화 지원
- JSON 백업, 확인 체크박스, `기록초기화` 문구, 마지막 확인창 도입
- 서버 초기화 시 트랜잭션과 `meta.generation` 증가. 과거 미전송 기록 재전송 차단
- 오래된 미전송 기록은 JSON 백업 후 별도 폐기할 수 있음
- 초기화 후 200/50 번호 슬롯 유지
- `yc2026-timer` Realtime Database URL/프로젝트 ID 사전 입력. Firebase 웹 앱 apiKey/appId 입력 필요

**경고:** 익명 인증은 사용자 식별 및 접근 통제가 아닙니다. 주소가 공개되면 제3자가 기록을 변경할 수 있어 운영 보안이 필요하면 관리자 인증으로 변경해야 합니다.
