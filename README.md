# 2026 연천피지컬 서바이벌 · 경기 기록관리 v1.3

**GitHub Pages 배포용 정적 웹앱. 개인전 001~200번과 단체전 01~50팀(팀당 주자 4명)이 기본 내장**되어 있습니다. 참가자 등록은 하지 않습니다.

## 사용 순서

1. 경기 계측 탭에서 **개인전** 또는 **단체전(4인 계주)** 선택
2. 번호 선택 → **계측 제어권 획득**(Firebase 연결 상태에서만 필요) → 시작/종료
3. 종료 즉시 기기에 우선 저장하고 Firebase에 동기화합니다. 다음 대기 번호 자동 선택
4. MC 전용 읽기 화면은 같은 주소 뒤 `?view=mc`로 접속합니다. **이 화면은 UI에서만 읽기 전용**이며 링크를 바꾸면 누구나 수정 화면에 접근할 수 있습니다.
5. 운영·백업 탭에서 개인/단체/전체 결과 CSV를 내려받을 수 있습니다.

## 기록 초기화

운영·백업 → 기록 초기화 관리 → **JSON 백업 다운로드** → 파일 확인 → 범위 선택(개인전/단체전/전체) → `기록초기화` 입력 → 마지막 확인을 누릅니다.

- 개인전만 초기화하면 단체전 기록은 유지합니다. 반대도 같습니다.
- 전체 초기화하면 모든 계측 기록을 지우고 **001~200번/01~50팀 슬롯을 유지**합니다.
- Firebase가 연결되어 있으면 모든 화면에 초기화가 전파됩니다. 현재 진행 중 경기나 미전송 기록이 있을 때는 초기화를 차단합니다.
- Firebase가 미연결 상태이면 **해당 기기의 기록만 초기화**합니다.
- 다른 기기의 오래된 미전송 기록이 초기화 후 다시 올라오는 것을 막기 위해 데이터 초기화 세대(generation)를 비교합니다. 충돌하는 대기열은 백업 후 폐기 절차가 필요합니다.
- **JSON 백업을 내려받는 것은 다운로드 요청이지 파일이 손상 없이 저장됐다는 기술적 보증이 아닙니다. 실제 파일을 확인하세요. JSON 백업 자동 복원 기능은 아직 없습니다.**

## 로그인 없는 실시간 공유

- 로그인 화면, 이메일 계정, 비밀번호가 없습니다. **Firebase 익명 인증**으로 연결합니다. Firebase Console에서 **Authentication → 로그인 방법 → 익명(Anonymous)** 을 활성화해야 합니다.
- Firebase Realtime Database 규칙은 `database.rules.json`을 별도로 적용해야 합니다. 등록/초기화/계측을 할 사람에게 계정 로그인을 요구하지 않는 방식이므로 **웹 주소를 아는 모든 방문자가 데이터 수정·삭제를 시도할 수 있습니다**. 익명 인증은 사용자 신원이나 관리자 권한을 입증하지 않습니다.
- 행사 전에만 오픈하고 외부에 링크를 널리 공유하지 마세요. **공식 경기 결과를 안전하게 운영하려면 인증과 권한 분리를 권장합니다.**
- Firebase 초기 설정 값은 `js/firebase-config.js`에 작성합니다. 공개 클라이언트 설정 파일에 비밀번호, Admin SDK, 서비스 계정키를 넣지 마세요.
- `yc2026-timer` 프로젝트 ID와 데이터베이스 URL은 제공된 Firebase 스크린샷으로 확인된 값이 사전 입력돼 있습니다. `apiKey`, `appId`는 Firebase 콘솔의 웹 앱 설정값으로 채워야 합니다.

## 배포

1. 이 ZIP을 압축 해제하고 **파일을 모두** GitHub 저장소의 최상위 폴더에 업로드합니다. `index.html`, `js/`, `style.css`, `database.rules.json` 등을 유지합니다.
2. Settings → Pages → Deploy from a branch → main / (root) 저장
3. Firebase 프로젝트 내 웹 앱 생성(</>), 익명 Authentication 활성화, Realtime Database 규칙 Publish
4. `js/firebase-config.js`에 웹 앱 연결값 입력 및 GitHub에 커밋
5. 정상 연결, 001번 기록 → 별도 기기 MC 조회, 계주 01팀 기록, 초기화 개별/전체, 30초 네트워크 장애/복구를 실제 환경에서 검증합니다.

**Firebase 설정을 입력하지 않으면 단독 기기 저장 모드로 동작하며 다른 기기에 공유되지 않습니다.**

## 기술 및 제약

- 정적 HTML/CSS/JavaScript · IndexedDB 로컬 저장 · Firebase RTDB 실시간 동기화
- 계측은 `performance.now()` 기반, 종료 시 0.01초 단위 표시(수동 버튼 반응오차는 별개)
- 다른 계측 PC는 동시 수정하지 않도록 제어권을 임대(lease)하지만, 익명 공개 방식에서 **보안 경계는 아닙니다**.
- 200명·50팀 자동화 계측 시험 및 초기화 로직 시험 완료. Firebase 실제 접속, Rules 에뮬레이터, 멀티 디바이스 실시간 반영, 실제 행사장 긴 시간 운영은 **미검증**.

자세한 연결 순서는 `docs/SETUP_GUIDE.md`, 시험 근거는 `docs/TEST_REPORT.md`를 확인하세요.
