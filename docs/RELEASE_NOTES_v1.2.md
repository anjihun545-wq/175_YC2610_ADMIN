# 2026 연천피지컬 서바이벌 · v1.2 정식 UI 정리

## 반영 사항
- 개인전 001~200번 / 단체전 01~50팀 고정번호와 4인 계주 유지
- 화면의 임시 안내 문구 제거
- Firebase 미설정 시 오해 없도록 `서버 미연결 · 기기 저장` 표시
- Firebase 연결 중/연결 끊김/기록 전송 대기 중 새 경기 시작 차단
- 이미 시작된 경기는 오프라인에서도 종료 후 기기에 기록 저장 가능

## 검증 경계
- 로컬 브라우저 시나리오 시험은 TEST_REPORT.md 참조
- Firebase 실제 인증, 실시간 동기화, 권한규칙, 네트워크 장애 복구는 **아직 테스트하지 않음** (Firebase 프로젝트 연결 필요)
- 실제 행사장 정식 사용 전 운영자와 MC 각 기기에서 연결 시험 필수

## 버전 교체
GitHub Pages 저장소 루트 파일을 교체하세요. `js/firebase-config.js`에 실제 설정값이 있다면 먼저 백업하세요. 기존 Firebase 기록을 초기화하지 마세요.

- 기기 저장소 오류가 발생한 경우 계측 시작을 금지하고 오류를 화면에 표시합니다.
