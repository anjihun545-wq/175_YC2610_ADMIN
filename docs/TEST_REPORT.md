## 실행할 수 있는 자체 테스트

Node.js 22 이상에서 프로젝트 최상위 폴더로 이동 후:

```sh
node --check js/app.js
node --check js/core.js
node --check js/storage.js
node --check js/cloud.js
node --experimental-vm-modules tests/test_local.mjs
node --experimental-vm-modules tests/test_sync_guards.mjs
```

위 두 테스트는 **가상 저장소/가상 Firebase 동작 로직 테스트**입니다. 실제 Firebase 연결 완료를 증명하지 않습니다.

## 출시 판단

**Firebase 연동 전 정적 파일/핵심 로직 시험용 준비 완료. 현장 공식 경기 기록 운영 승인 전.**

GitHub에 반영한 뒤 Firebase 프로젝트·접근 제어를 실제로 연결하고, 여러 기기의 기록 일치 및 비정상 종료 복구를 검증해야 정식 행사 운영으로 전환할 수 있습니다.
